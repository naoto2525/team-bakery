## 見た目のルール(style.css)

- メインの色:(例:茶色 #8b5a2b)
- 背景の色:(例:クリーム色 #fff8ee)
- 文字の大きさ:(例:本文 16px)
- フォント:(例:sans-serif)

## チームのルール

- main に直接 push しない(必ず枝を作って PR を通す)
- 枝の名前は feature-〇〇
- PR に「何をしたか」「確認したこと」を書く
- マージに必要な Approve の数:(1 か 2)
- 始める前に main をプルする
- style.css を変えるときは、先にチームに声をかける
